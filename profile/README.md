# ssh 3群

微信群「ssh 3群」的 GitHub 组织，用于维护群生态，也欢迎群友分享自己的项目。

## 仓库命名约定

- `group-` 是 SSH 群官方生态仓库的保留前缀，用于群官方维护的基础设施、数据和服务。
- 群友独立项目使用自己的名称，不使用 `group-` 前缀，即使托管在本组织内，也不代表群官方生态。
- `.github` 是 GitHub 特殊仓库，用于组织介绍和公共协作规范，保留原名。

## Repo 计划

### group-site — 群生态网站

- 独立保存网站代码，负责浏览、检索与展示。
- 从 `group-archive` 读取记录与日报，从 `group-members` 读取成员资料。
- 网站访问权限独立控制；私有仓库的读取通过服务端或构建阶段完成，不向浏览器暴露 GitHub 凭据。
- 后续再建。

### group-archive — 群聊档案

- 保存原始聊天记录（chatlog）、日报（report）与话题覆盖索引。
- 作为后续网站的数据源，不放网站代码。
- 私有仓库，仅授权成员访问。

### group-members — 三群成员

- 保存三群真实成员名单、成员展示数据与群配置。
- 通用代码继续维护在 [GinWU05/wegroup-members](https://github.com/GinWU05/wegroup-members)，本仓库引用固定版本，不复制通用代码。
- 包含真实名单，建议设为私有仓库。

### group-summary — 群聊总结实现

- 保存采集、清洗、总结、日报渲染的代码与流程。
- 生成的原始记录和日报写入 `group-archive`，与实现代码分开保存。
- 暂缓创建，后续再建。
